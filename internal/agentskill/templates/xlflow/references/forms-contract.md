# FormSpec Property Contract

Generated from xlflow's shared UserForm contract. Read [property guidance](forms-properties.md) for examples, edit semantics and compiler limits. Do not edit this file by hand; maintainers regenerate it with `pnpm docs:generate-form-skill`.

Use the exact camelCase keys below. `stringArray` means an array of strings; `objectArray` means an array of objects. Required fields are required when the enclosing object exists. A dash in Values means this metadata lists no finite set; additional semantic and compiler validation still applies. `any` does not promise persistence of arbitrary values. Snapshot-only fields are captured metadata, not edit requests, except legacy nested `controls`, which is accepted as input and normalized to the canonical flat root `controls` array. Use the flat format for new authoring.
